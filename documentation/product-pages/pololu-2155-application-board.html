Overview

This application board makes it easy to try out a wide variety of peripherals with an ARM mbed NXP LPC1768 development board. The mbed board plugs into a double row of header pins, making it easy to access all of the pins with jumper wires.

More information about the mbed application board can be found at the mbed application board cookbook page.

This application board is designed for and requires an ARM mbed NXP LPC1768 Development Board (sold separately). Not all features will work if used with the ARM mbed NXP LPC11U24 Development Board.

Features

  • 128×32 graphical backlit LCD
  • 5-way joystick
  • 2 potentiometers
  • 3.5mm audio jack (analog out)
  • 3.5mm audio jack (analog in)
  • Speaker
  • 3-axis ±1.5g accelerometer
  • 2 RC servo headers
  • RGB LED
  • Temperature sensor
  • Socket for XBee (Zigbee) or RN-XV (Wi-Fi)
  • RJ45 ethernet connector
  • USB-mini-B connector
  • USB-A connector
  • 1.3mm DC power jack input
